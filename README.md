# <img src="www/SEA-AD-logo.png" alt="SEA-AD logo" height="35"> SEA-AD Multiregion Gene Expression Viewer <img src="www/SEA-AD-logo.png" alt="SEA-AD logo" height="35">

The <b><a href="https://sea-ad.shinyapps.io/multiregion_gene_exploration/" target="_blank">SEA-AD Multiregion Gene Expression Viewer</a></b> is an interactive R Shiny application for exploring pseudobulk gene expression across brain regions, cell types, donors, and measures of Alzheimer’s disease progression. Users can search for a gene, review summary statistics, filter observations using study metadata, and create trajectory, heatmap, dot, or violin plots. The viewer retrieves only the selected gene from AWS, which keeps startup and interactive queries practical while supporting a large multiregion expression dataset.
